# Ziegenfisch Royale

Halb Ziege. Halb Fisch. 100 % Sieg.

Ein eigenes 3D-Battle-Royale im Browser (Three.js): 1 Spieler gegen 99 Bots, Blubb-Zeppelin, Sturm, Loot und Truhen.

**Spielen:** https://romolinidennis73-oss.github.io/ziegenfish-royal/

Auf dem iPhone: Link in Safari öffnen, Teilen-Knopf, „Zum Home-Bildschirm“. Danach startet das Spiel im Vollbild wie eine App.

Der Quellcode liegt in `source/`. `python3 build.py` (im Ordner `source/`) baut `dist/index.html`, die als `index.html` hier im Hauptordner liegt.
